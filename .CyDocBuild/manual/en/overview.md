## Using this guide {#getting-started}

CyGameSDK is a native editor foundation in early development. It supplies a Sandbox adapter and reusable UI, document and authoring systems. It does not automatically support an arbitrary game. Version 0.29.0 is a source release under MIT.

- Current graphical host: Windows x64 / Direct3D 11.

- The interface defaults to English and preserves an explicitly selected language.

- Projects, working assets and settings live in the installation’s data folder. Keep backups and use a separate destination for a derived SDK.
